# Code of Conduct

We want technical disagreement without harassment.

Expected behavior:

- critique ideas and evidence, not a person's identity;
- state uncertainty and distinguish facts from proposals;
- respect copyright, provenance and privacy;
- use synthetic data in examples;
- stop when a maintainer asks to move a security report to a private channel.

Unacceptable behavior:

- harassment, threats, discrimination or doxxing;
- publishing credentials or private data;
- impersonating a maintainer, contributor or official release;
- using the repository to promote financial returns or fraud;
- knowingly submitting copied or unlicensed artwork.

Maintainers may edit or remove abusive content and may restrict participation
while preserving security evidence where necessary.
